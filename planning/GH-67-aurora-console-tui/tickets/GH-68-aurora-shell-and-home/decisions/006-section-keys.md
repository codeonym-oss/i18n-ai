# 006: `ctrl+o` Home, `ctrl+n` Run, `v` Review

**Date:** 2026-11-10 (ticket pass, Q6; agreed: "ok", to the recommended option 1)

**Question:** which keys move between the sidebar's sections?

**Decision:** **the shell binds three keys:** `ctrl+o` Home (overview); `ctrl+n` Run, the run going or else a new
setup; `v` Review, as today. The sidebar also takes a click, or `tab` then the arrows. In Review, `b` goes back to
the section it was opened from. Every key bound today keeps its meaning.

- **Why:** the design's hints ("⌃N new run · v review"); nothing that works today changes.
- **Not chosen:** `F1`–`F3` (hidden behind `fn` on many laptops, little discoverable); `1`–`3` (lost whenever a
  text field has focus, half the setup).
