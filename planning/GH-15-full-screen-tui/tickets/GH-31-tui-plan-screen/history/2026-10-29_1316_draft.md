# Plan a TUI run as a files × locales grid, with single cells turned off

## Problem

Between setup and run, the TUI should show what the run will do, and let the person leave parts out. The precheck
(`ScanLocaleTreeQuery`) already gives each file × locale's counts, but `GenerateLocalesCommand` can only leave out
a whole locale or a whole file.

## The change

- `GenerateLocalesCommand` takes a set of skipped (file, locale) pairs; the handler leaves those jobs out before the
  engine starts, and the receipt does not list them (story decision 005).
- **Plan screen**, after setup: files × locales as a grid, each cell new, fill or skip with its message count,
  files that do not qualify shown with their reason. A cell, a row or a column turns off; rows and columns map to
  `include`/`exclude` and `targets`, single cells to the skip set.

## Out of scope

- A CLI `--skip` flag (decision 005).

## Done when

- [ ] A handler test: a skipped pair is never sent to the engine, and the other jobs of its file and locale are.
- [ ] A `Pilot` test turns one cell off on an `examples/` tree, runs, and finds that file × locale not written.
